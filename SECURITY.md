# Security policy

## Reporting a vulnerability

Please do not open a public issue. Report it privately through GitHub's
[private vulnerability reporting](https://github.com/andras-tkcs/html-artifact-deploy/security/advisories/new),
or by e-mail to at+github@felhasznalo.name.

Include what an attacker can do, the version affected, and the steps to reproduce. You will get an
acknowledgement within five working days.

## Supported versions

Only the latest stable release receives security fixes.
